# Known Issues

## KI-001 — التحقق على جهاز Android فعلي غير منفذ

تم تشغيل Metro والنفق العام، لكن لم يصلنا بعد دليل من جهاز Android فعلي يثبت فتح التطبيق والتفاعل معه.

**الحالة:** Open.

## KI-002 — محرك المستند والتخزين غير منفذين

الواجهة الحالية Foundation/Dashboard وليست محرراً بصرياً كاملاً. لم تُنفذ بعد مشاريع، صفحات، عناصر، حفظ محلي، قوالب، أصول أو تصدير.

**الحالة:** Open.

## KI-003 — حدود PDF والاعتماديات Native غير محسومة

لم تُعتمد مكتبة PDF أو Canvas أو معالجة صور Native. يجب اتخاذ القرار عبر spike مستقل قبل إضافة اعتماديات قد تتطلب Development Build.

**الحالة:** Open.

## KI-004 — لا يوجد Push للمرحلة الحالية بعد

التغييرات المحلية اجتازت الفحوص المذكورة في سجل التنفيذ، لكنها لم تُسجل بعد في commit أو تُرفع إلى GitHub.

**الحالة:** Open.
