# Developer Guide

## الحالة الحالية

Books Designer في بداية مرحلة التنفيذ. يحتوي المستودع على دراسة التصميم التحريري، وتقرير معماري تأسيسي، وسجلات التنفيذ. لا تعتبر الميزات غير الموجودة منفذة.

## متطلبات البيئة

يلزم Node.js وnpm وExpo SDK 54. يجب تثبيت الاعتماديات من `package-lock.json` بعد إنشائه، وعدم تشغيل `npx expo` بدون مشروع أو السماح له بجلب SDK أحدث.

## سير العمل

ابدأ بقراءة `README.md` و`docs/architecture-analysis.md` و`docs/PROJECT_STATE.md` و`docs/EXECUTION_LOG.md` و`docs/FEATURE_STATUS.md`. افحص `git status` و`git remote` قبل تعديل الملفات. بعد كل خطوة، افحص diff وشغّل الاختبار المناسب وسجل النتيجة قبل إنشاء commit.

## قواعد المعمارية

تتجه الاعتماديات من Presentation إلى Application إلى Domain، وتنفذ Infrastructure المنافذ المعرفة في الداخل. لا تحتوي Domain على imports من React Native أو Expo أو قاعدة البيانات. نموذج المستند هو مصدر الحقيقة، أما مكونات العرض فهي إسقاط له.

## التشغيل

لن يُضاف أمر تشغيل أو tunnel إلى هذا الدليل بوصفه متحققاً حتى يوجد مشروع Expo فعلي ويجتاز فحص SDK 54. عند توفر المشروع، يوثق الأمر الفعلي والرابط الناتج وحالة QR في سجل التنفيذ.
