# Known Issues

## KI-001 — التحقق على جهاز Android فعلي غير منفذ

تم تشغيل Metro والنفق العام، لكن لم يصلنا بعد دليل من جهاز Android فعلي يثبت فتح التطبيق والتفاعل معه.

**الحالة:** Open.

## KI-002 — محرك المستند والتخزين غير منفذين

تم حل جزء التخزين الخاص بمكتبة المشاريع عبر SQLite. ما زال المحرر البصري، الصفحات، العناصر، القوالب، الأصول والتصدير غير منفذة.

**الحالة:** Open.

## KI-003 — حدود PDF والاعتماديات Native غير محسومة

لم تُعتمد مكتبة PDF أو Canvas أو معالجة صور Native. يجب اتخاذ القرار عبر spike مستقل قبل إضافة اعتماديات قد تتطلب Development Build.

**الحالة:** Open.

## KI-004 — لا يوجد Push للمرحلة الحالية بعد

تم حل المشكلة السابقة. commit المرحلة الأخيرة قبل Phase 2 مرفوع إلى `origin/main` ومطابق للـlocal HEAD.

**الحالة:** Resolved.

## KI-005 — npm audit reports transitive vulnerabilities

نتيجة `npm audit --omit=dev` الحالية: 1 منخفضة، 24 متوسطة، و2 عالية، بإجمالي 27 ثغرة عابرة أو مرتبطة بسلسلة Expo/Metro. لم أستخدم `npm audit fix --force` لأنه قد يغيّر إصدارات Expo SDK 54 أو يكسر التوافق. يجب تحليلها وترقيتها ضمن حدود SDK 54 في مهمة أمنية مستقلة.

**الحالة:** Open.
